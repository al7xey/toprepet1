# Интерфейс TopRepet

- `routes/` содержит маршруты гостя, авторизации, ученика, репетитора и администратора.
- `layout/` содержит публичную шапку, мобильную и настольную навигацию кабинетов.
- `ui/` содержит общие поля, кнопки, модальные окна, панели, карточки репетиторов и календарь.
- `api/contract.ts` и `api/types.ts` описывают контракт. `api/http.ts` использует сессионную cookie и запрашивает данные из Django. По умолчанию Vite проксирует `/api` на локальный сервер.
- `tr.css`, `home.css` и `ui/kit.css` определяют раскладки и компоненты. `ui/liquid-glass.css` определяет оформление стеклянных поверхностей.

Локальный запуск и проверка описаны в [README](../../README.md).
