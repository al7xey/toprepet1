# Проверка интерфейса TopRepet — 23 ноября 2026

## Направление
Белая тема на всех экранах, оранжевые основные действия, Manrope и общие компоненты проекта. Telegram — ориентир для структуры мессенджера, а не для тёмной палитры.

## Исправлено
- Иконки общего UI-кита наследуют цвет элемента через currentColor: активные, неактивные, опасные и заполненные кнопки используют один SVG.
- Модальные окна учитывают системное уменьшение движения при жесте закрытия.
- Меню сообщений больше не находится внутри aria-hidden; используется общий Modal с ограничением фокуса, Escape и возвратом фокуса.
- Добавлен профиль собеседника с переходом в анкету, поиском и фотографиями из текущего диалога. Личные контакты не раскрываются.
- Поиск работает как по списку диалогов, так и внутри открытой переписки, включая пустой результат.
- Чтение истории не сбрасывается к последнему сообщению при фоновом обновлении.
- Долгое нажатие допускает небольшой сдвиг пальца и отменяется при прокрутке.
- Вторичный текст мессенджера затемнён после измерения axe: прежний #737987 на белом давал 4.36:1.
- Удалено повторное объявление MessageCard в контракте.

## Проверки
- Матрица основных публичных страниц и кабинетов ученика, репетитора и администратора: 320, 768, 1920 px — без горизонтального переполнения, с доступным основным заголовком.
- Браузерный сценарий мессенджера: поиск диалога, профиль, поиск по тексту, открытие действий клавиатурой, отправка, белый фон — телефон и ПК.
- axe WCAG A/AA на публичных страницах и кабинетах; заголовки, размеры контролов, навигация без 404 и мобильная шапка — отдельный существующий набор quality.
- Модульные проверки: 37 пройдено, 14 пропущено (контракт настоящего API требует отдельного окружения).

## Границы проверки
Проверка маршрутов и общих компонентов не равна новой отрисовке каждого файла. В этом изменении переработан мессенджер и исправлены общие иконки и модальные окна. Остальные страницы прошли проверку существующего интерфейса; они не заменены новыми макетами.

Из семейства better-* установлены interface, layout, colors и ui. Отдельные better-accessibility, better-writing, better-typography и better-motion отсутствуют; утверждения о прохождении этих отдельных скиллов не делаются. Настоящий API, push-уведомления, голосовые звонки, редактирование, пересылка и закрепление сообщений в это изменение не входят.
