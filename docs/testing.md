# Тестирование

| Команда | Что проверяет |
| --- | --- |
| `pnpm exec tsc --noEmit` и `pnpm lint` | Типы и линтер фронтенда |
| `pnpm test` | Модульные тесты фронтенда |
| `python -m pytest` из `backend` | Бизнес-правила, роли, доступ к файлам, расписание и бронирование. Для проверок конкурентного бронирования нужен PostgreSQL |
| `bash backend/scripts/contract.sh` | Контракт фронтенда с Django на отдельной SQLite-базе |
| `bash backend/scripts/e2e.sh` | Браузерные проверки с Django на отдельной SQLite-базе |
| `pnpm build` | Рабочая сборка, пререндер и проверки SEO и аналитики |

Браузерные тесты требуют установки Chromium через `pnpm exec playwright install chromium`. Проверки основной навигации и раскладки можно запустить локально с пустой базой через `pnpm e2e` при запущенном Django и готовой сборке `pnpm build`. Скриншоты и трассировки упавших тестов сохраняются в `test-results/`.
